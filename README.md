# Anatomy Sandbox

An Android-first 3D anatomy learning sandbox built with Unity 6.3 LTS.

> **Educational toy only.** Vital-sign values are fictional approximations and are not medically accurate, diagnostic, or suitable for real-world medical decisions.

## Current foundation

- A procedural, stylized human mannequin built from Unity primitive meshes.
- Basic visible internal organ placeholders and skeletal landmarks.
- Body-part selection and hide/restore behavior.
- A fictional physiology scenario controller and vital-sign data model.
- Touch/mouse drag rotation and pinch/scroll zoom.
- A GitHub Actions workflow to build an Android ARM64 APK in the cloud.

## Project setup

The repository is now structured as a Unity project:

- `Assets/AnatomySandbox/Scripts` — runtime anatomy, interaction, and simulation code.
- `Assets/Editor/AndroidBuildSetup.cs` — creates the initial MainLab scene and configures Android build settings in CI.
- `Assets/AnatomySandbox/Scenes/MainLab.unity` — generated by the build setup the first time the cloud build runs.
- `Packages/manifest.json` — Unity packages, including URP and UGUI.
- `ProjectSettings/ProjectVersion.txt` — Unity 6.3 LTS editor version.
- `.github/workflows/android-apk.yml` — cloud Android build workflow.

The startup scene is generated by the build method so the first APK can be built without manually opening the Unity Editor. The generated scene is created inside the build runner and is not automatically committed back to GitHub.

## Build an Android APK with GitHub Actions

1. Open the repository's **Settings → Secrets and variables → Actions**.
2. Add the Unity licensing secrets described below.
3. Open **Actions → Android APK → Run workflow**. A push that changes Assets, Packages, ProjectSettings, or the workflow also starts a build.
4. When the run finishes, open its summary and download the **AnatomySandbox-Android-APK** artifact ZIP.
5. Extract the APK and install it on an Android device. Android may ask you to allow installation from the app used to open the file.

### Required GitHub Actions secrets

For Unity Personal (free), GameCI expects:

- `UNITY_LICENSE` — the full text of the activated Unity `.ulf` license file.
- `UNITY_EMAIL` — the email address for the Unity account.
- `UNITY_PASSWORD` — the Unity account password.

Do **not** put these values in source files, commit them, or send them in chat. Enter them only in GitHub's encrypted Actions secrets. If you use Unity Pro/Plus instead, follow GameCI's professional-license setup; that uses `UNITY_EMAIL`, `UNITY_PASSWORD`, and `UNITY_SERIAL` rather than the Personal-license setup.

For a Personal license, use Unity Hub on a computer once to sign in and activate **Unity Personal**, then locate the generated license file. Typical Windows location: `C:\\ProgramData\\Unity\\Unity_lic.ulf`. Copy the file's contents into the `UNITY_LICENSE` secret. The computer is needed for this one-time license setup, not for each cloud build. GameCI's official guide has the current steps: https://game.ci/docs/github/activation/

## Android build configuration

- Package ID: `com.intersprit.anatomysandbox`
- Architecture: ARM64
- Minimum Android API: 26
- Output path in the runner: `Builds/Android/AnatomySandbox.apk`
- Workflow artifact: `AnatomySandbox-Android-APK`

## Important limitations

- The generated body is a **placeholder**, not a realistic medical-grade anatomy model.
- The scene and APK are generated in CI; this setup has not yet been verified by a successful Unity cloud build. The first run is the real compile/build check.
- No visual animations are included at this stage, as requested.
- The current build is a foundation: detailed anatomy assets, a full interactive UI, labels, system-layer toggles, and richer simulation controls remain future work.
- The orbit controller currently uses Unity's legacy input API; the CI setup selects the legacy input handling mode for compatibility.

## Suggested asset sources

- Unity Asset Store: https://assetstore.unity.com/
- Sketchfab downloadable models: https://sketchfab.com/search?features=downloadable&q=human%20anatomy
- Mixamo for humanoid character rigging and later animations: https://www.mixamo.com/

Before importing any asset, check its license, Unity/URP compatibility, file format, and whether individual organs are separate meshes. A model with separately selectable named organs is more useful than one fused mesh.

## Safety

This project is intended to explain anatomy and relationships between body systems using non-graphic fictional demonstrations. It should not depict a real person's suffering or be used as a medical tool.
